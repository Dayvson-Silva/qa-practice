# 🚀 Projeto QA - Cypress

Este é um projeto de automação de testes utilizando o Cypress para validar funcionalidades de cadastro e login.

## 📌 Funcionalidades testadas

- ✅ Cadastro de usuário com sucesso
- ✅ Login com usuário cadastrado
- ✅ Tentativa de login sem cadastro
- ✅ Validações de autenticação

---

## 🛠 Tecnologias utilizadas

- JavaScript
- Cypress
- Node.js
